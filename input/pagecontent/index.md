# SmartFOX Minimal Set Implementation Guide

This RHIR Implementation Guide has the prurpose to define a minimal FHIR bundle for a data donation process. This FHIR bundle containes the key elements which are requiered for the forwarding of this information into a FOX BOX which makes it later possible to donate data. In this IG you can find the profiles and elements requiered to fill a minimal bundle for the data donation process.
